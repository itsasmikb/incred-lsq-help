# InCred LeadSquared Help (public version, no API key)

All files sit at the top level. Personal details (customer and staff names, emails and phone numbers)
are blurred in the screenshots so the site can be public.

Deploy: upload every file to a GitHub repository, import it into Vercel (Framework Preset: Other)
and deploy. With no SITE_USERNAME / SITE_PASSWORD set, anyone with the link can open it.
To add a login later, set both variables in Vercel and redeploy.

To update answers, edit kb.md (manual) or answers.json (topic buttons) in GitHub.
Before adding new screenshots, blur any names, emails or phone numbers in them.
